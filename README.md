## Installation

1. We provide a [Docker image](./docker) for easy and fast installation. To build and run the container, please use the following commands:
   ```shell
   bash ./docker/build.sh
   bash ./docker/run.sh
   ```
   As a result, you will have your filesystem available in the `/mounted` subfolder inside the container.

2. Next, inside the container go to the repository folder and build and install BBSplat and other GPU-dependent libraries:
   ```shell
   cd /mounted/path/to/NBAvatar
   bash bbsplat_install.sh
   ```
   
## Dataset Preparation

Please download hand-face interaction dataset: https://github.com/soshishimada/DecafDatasetScript

And preprocess the dataset as described in the instruction in the [README.md](https://github.com/soshishimada/DecafDatasetScript/blob/main/README.md)

We use [SAM3](https://github.com/facebookresearch/sam3) segmentation model to mask head and hands from the background.

First install the SAM3 environment as described in the [./sam3/README.md](./sam3/README.md). Then, with this environment activated, run the following command from the repository root to prepare segmentation masks:
```shell
bash generate_masks.sh /path/to/DecafDataset
```
Here ```/path/to/DecafDataset``` is the root of the preprocessed dataset that contains the ```train``` and ```test``` folders. For every camera of every subject (S1–S4), the script saves raw SAM3 masks to the ```sam3_fixed_k``` folder and the final preprocessed masks, used for training, to the ```sam3_preproc``` folder.

## Training

All training and evaluation commands are run inside the Docker container (after ```bash bbsplat_install.sh```) from the repository root. Inside the container your filesystem is available under ```/mounted```, so all paths in the configs should start with ```/mounted```.

There are two configs per subject in ```./configs```:
* ```dnr_billboards_S*.yaml``` — used for training and for the novel-view evaluation;
* ```dnr_billboards_S*_novel_pose_eval.yaml``` — used only for the novel-pose (self-enactment) evaluation.

In **all eight** configs update the following paths:

| Field | Description |
|-------|-------------|
| ```log_dir``` | Folder where checkpoints and test renders will be saved |
| ```trainer.params.model_path``` | Root of the prepared Decaf dataset (the folder containing ```assets```, ```train``` and ```test```) |
| ```dataset_train.params.dataset_path``` | Root of the prepared Decaf dataset |
| ```dataset_test.params.dataset_path``` | Root of the prepared Decaf dataset |

For example, if the dataset is located at ```/data/DecafDataset``` on your machine, set ```model_path``` and both ```dataset_path``` fields to ```/mounted/data/DecafDataset/```.


To train one avatar, run:
```shell
python main.py --base=./configs/dnr_billboards_S1.yaml
```

To train all avatars, run:
```shell
bash run_train.sh
```

Each training run creates a new folder ```<log_dir>/dnr_billboards_S*/<YYYY_MM-DD_HH-MM>/``` with checkpoints in ```checkpoints/```:
* ```trainer_iter_<N>.pth``` — checkpoints saved every 10k iterations;
* ```trainer_iter_100000_mse_ft.pth``` — the renderer fine-tuned with MSE loss for 10k additional steps;
* ```trainer_iter_100000_mse_soup.pth``` — the renderer weights averaged between ```trainer_iter_100000.pth``` and ```_mse_ft.pth``` (```mse_soup_alpha: 0.8```). 

## Test and Evaluation

Evaluation consists of two steps: rendering the test set with ```test.py``` and computing metrics on the renders with ```eval_metrics.py```.

**1. Rendering.** Pass the config of the protocol you want to evaluate and the checkpoint:
```shell
# Novel view
python test.py --base=./configs/dnr_billboards_S1.yaml \
    --pretrained=/mounted/path/to/checkpoints/dnr_billboards_S1/<YYYY_MM-DD_HH-MM>/checkpoints/trainer_iter_100000_mse_soup.pth

# Novel pose
python test.py --base=./configs/dnr_billboards_S1_novel_pose_eval.yaml \
    --pretrained=/mounted/path/to/checkpoints/dnr_billboards_S1/<YYYY_MM-DD_HH-MM>/checkpoints/trainer_iter_100000_mse_soup.pth
```
The renders are saved to ```<log_dir>/<config name>/test-<YYYY_MM-DD_HH-MM>/```.

To render the novel-view test sets of all avatars, update the ```--pretrained``` checkpoint paths in ```run_eval.sh``` and run:
```shell
bash run_eval.sh
```

**2. Metrics.** Run ```eval_metrics.py``` on the folder generated by ```test.py```:
```shell
python ./src/scripts/eval_metrics.py --data_dir=<log_dir>/dnr_billboards_S1/test-<YYYY_MM-DD_HH-MM>
```
The script calculates PSNR, SSIM and LPIPS averaged over all frames of the subject.
